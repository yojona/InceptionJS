# Code of conduct

Everyone taking part in this project, in issues, pull requests, discussions and any
other space it runs, is expected to follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Please read it; it is short.

In plain words: be respectful, assume good faith, criticize code and ideas rather than
people, and do not harass anyone.

## Reporting

To report behavior that breaks it, use GitHub's private vulnerability reporting form on
the repository (the **Security** tab), and start the title with "Conduct". Only the
maintainers see it. Reports are handled in confidence.

The maintainers enforce this code as described in the Covenant's enforcement
guidelines.
